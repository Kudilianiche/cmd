# Техническое задание

## HTTP-сервер для выдачи статических файлов

### 1. Назначение сервиса
- Создать сервис для удобного чтения японских комиксов (манги) или иных графических произведений в формате CBR или иных. Сервер будет отвечать за обработку запросов и выдачу необходимых файлов пользователю

### 2. Основные функции
- Прием запросов от пользователей
- Поиск запрашиваемых CBR или иных файлов
- Выдача файлов

### 3. Требования к работе
- Программа должна принимать настройки для указания директории с статическими файлами и порта, на котором запускать сервер
- HTTP-сервер должен правильно обрабатывать запросы на различные типы файлов (например CBR)
- Реализована обработка ошибок, связанных с отсутствием запрашиваемых файлов или неверными запросами
- Сервер должен быть способен обслуживать несколько клиентов одновременно и делать это быстро

### 4. Технические характеристики
- Работа через HTTP-протокол
- Поддержка формата файлов: CBR или иные
- Работа на языке программирования Go

### 5. Ожидаемые результаты
- Реализован алгоритм
- Реализовано разделение на слои (транспортный, хранения и т.д.)
- Реализовано API сервиса
- Реализован консольный пользовательский интерфейс
- Написаны юнит-тесты
- Написаны интеграционные тесты
